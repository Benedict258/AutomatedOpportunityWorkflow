# Taxonomy

Machine-readable taxonomies for Opportunity Intelligence System.

Files:
- opportunities.yaml
- government.yaml
- cybersecurity.yaml
- technology.yaml
- policy.yaml
- international-affairs.yaml
- fellowships.yaml
- certifications.yaml
- events.yaml
- news.yaml

ID conventions:
- lowercase
- dot-separated hierarchy
- stable

Each node supports id, name, parent, description, active, aliases, keywords, related_to.
